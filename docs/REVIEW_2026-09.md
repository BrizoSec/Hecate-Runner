# Hecate-Runner review, September 2026

*Historical record. Reviewed and remediated 2026-09-24; not maintained since.*

This is the list of issues found and fixed in the September 2026 code and
architecture review. It describes the codebase as of that date and makes no
claim about what has been found since: later problems and their fixes are in
the commit history of both repositories.
For how the pipeline works today, see [ARCHITECTURE.md](ARCHITECTURE.md).

## Issues resolved in that review

### 1. Data Integrity & Architecture Fixes
* **Non-Atomic File Writes (Fixed):** File generation routines (including `cisa_kev.py`, `otx_poller.py`, `misp_poller.py`, `rss_poller.py`, and crucially `hunt_writer.py` for draft rendering) previously used the non-atomic `path.write_text()`. They now uniformly utilize `atomic_write_text` to prevent file corruption or permanent truncation upon receiving a `SIGKILL` mid-write.
* **Quota & Cursor Desynchronization (Fixed):** The orchestrator's state save and CTI acknowledgment execution were shifted. They now trigger immediately after the draft is initialized on disk and *before* multi-minute LLM drafting (Sigma rules). This guarantees that a timeout during Sigma generation no longer leads to quota leakage, duplicate draft files, or infinitely re-polling the same CTI.
* **Environment Context Thrashing (Fixed):** `hecate_client.py` was refactored to cache the dotenv configuration upon initialization, preventing linear disk I/O penalties during heavy `.env` context swapping across subprocess wrapper boundaries.

### 2. Triage & Parsing Logic Fixes
* **CTI Tag Normalization (Fixed):** Added the `"entry_tags"` metadata standardization to the `misp` and `otx` providers. Previously, the intake triage system (`cti_triage.py`) failed to apply categorization filtering to these sources due to differing internal metadata shapes.
* **Regex Substring False Positives (Fixed):** `platforms_named_in` inside `orchestrator.py` now enforces regex word boundaries (`\b`), ensuring that substrings like "isaac" don't falsely trigger the "SaaS" platform filter during draft scoping.

### 3. Auditing & Routing Fixes
* **Indicator Sweep Maps (Fixed):** Added explicit support for `"ip-src|port"` MISP indicators to route correctly to firewall telemetry instead of degrading to an unsupported generic output.
* **Grounding Audit Extensions (Fixed):** The audit heuristic `_looks_like_a_filename` was broadened to properly ignore standard extensions (`.bin`, `.pid`, `.local`, `.db`, `.bak`, `.old`), stopping valid files from being wrongly flagged as hallucinated C2 domains.
* **State Drift Documentation (Fixed):** Cleaned up outdated architectural comments in `grounding.py` regarding subprocess bounds.
